# Rig core

`SkeletonDefinition` owns a stable-ID rest-pose hierarchy. Bone coordinates use the owning mesh's avatar-rest space; pose transforms are deliberately not inferred from the Unity scene.

`SkinBinding` binds every render mesh vertex to one to 32 explicitly named bones and normalizes each vertex's positive weights. It pins the mesh topology hash and skeleton content hash so a later topology or rig change cannot silently reuse the binding. `SkinBindingEditing` provides deterministic selected-vertex reassignment, multi-bone blending, duplicate-safe target replacement, and explicit rebind shared by the GUI and future commands. `PoseEditing` changes one bone's XYZ Euler rotation, retains the Z-only compatibility helper, and can explicitly rebind a complete pose after rest skeleton changes. `SkeletonEditing` moves rest bone head/tail positions while changing the skeleton identity. `SkinDeformer` applies a complete pose using rest-relative affine transforms and returns a position-deformed mesh while retaining source attributes. `MorphTarget` and `MorphSet` store sparse rest-space position, normal and tangent deltas pinned to mesh topology; `MorphDeformer` applies 0..1 weights without baking a pose, and `MorphCodec` persists the set as strict `NYRM` v2 while reading v1 assets. GLB import/export retains NORMAL/TANGENT morph deltas when matching base attributes exist and reports an explicit warning when a source lacks those base attributes. Graph nodes persist the rig and morph assets; the workbench exposes a compact Morph target/weight editor. Humanoid presets and export remain later work. The Windows Rig panel includes brush-style weight paint with a radius in screen pixels and one Undo per drag.

`SpringBoneJointSettings`, `SpringBoneChain`, and `SpringBoneColliderGroup` form a Unity-independent, bounded preview input. `SpringBoneSimulator` advances detached Verlet state, applies stiffness/gravity/drag, keeps each tail at its rest length, resolves sphere colliders, and returns a complete `PoseSet`; it does not know VRM node indices, Unity scene objects, or runtime serialization. A later adapter must map imported VRM nodes to stable `BoneId` values and connect the result to the workbench/runtime.

`RigCodec` stores the skeleton and binding in a strict `NYRG` v1 binary asset, with standalone `NYRS`/`NYRB` payloads for graph nodes. `PoseCodec` stores complete poses as `NYRP` v1, and `MorphCodec` stores sparse targets as `NYRM` v1. Reading requires the original mesh and skeleton where applicable and rejects changed identities, invalid counts, malformed text, or trailing bytes before a value is published.
