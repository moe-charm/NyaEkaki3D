# Rig core

`SkeletonDefinition` owns a stable-ID rest-pose hierarchy. Bone coordinates use the owning mesh's avatar-rest space; pose transforms are deliberately not inferred from the Unity scene.

`SkinBinding` binds every render mesh vertex to one to four explicitly named bones and normalizes each vertex's positive weights. It pins the mesh topology hash and skeleton content hash so a later topology or rig change cannot silently reuse the binding. `SkinBindingEditing` provides deterministic selected-vertex reassignment, multi-bone blending, duplicate-safe target replacement, and explicit rebind shared by the GUI and future commands. `PoseEditing` changes one bone's XYZ Euler rotation, retains the Z-only compatibility helper, and can explicitly rebind a complete pose after rest skeleton changes. `SkeletonEditing` moves rest bone head/tail positions while changing the skeleton identity. `SkinDeformer` applies a complete pose using rest-relative affine transforms and returns a position-deformed mesh while retaining source attributes. `MorphTarget` and `MorphSet` store sparse rest-space vertex deltas pinned to mesh topology; `MorphDeformer` applies 0..1 weights without baking a pose, and `MorphCodec` persists the set as strict `NYRM` v1. Graph nodes now persist the rig assets; humanoid presets, morph graph/UI, and export remain later work. The Windows Rig panel includes brush-style weight paint with a radius in screen pixels and one Undo per drag.

`RigCodec` stores the skeleton and binding in a strict `NYRG` v1 binary asset, with standalone `NYRS`/`NYRB` payloads for graph nodes. `PoseCodec` stores complete poses as `NYRP` v1, and `MorphCodec` stores sparse targets as `NYRM` v1. Reading requires the original mesh and skeleton where applicable and rejects changed identities, invalid counts, malformed text, or trailing bytes before a value is published.
